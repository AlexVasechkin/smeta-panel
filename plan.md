## Полезные команды

```bash
# База данных (Postgres 17 в Docker)
docker compose up -d          # поднять Postgres
docker compose down           # остановить (данные в томе pgdata сохраняются)
docker compose down -v        # остановить и удалить данные

# Приложение
php artisan migrate            # миграции
php artisan migrate:fresh --seed  # пересоздать БД с демо-данными
composer run dev               # Vite + сервер + очередь + логи (dev-режим)
```

> Postgres проброшен на хост-порт **5438** (5432 занят другим сервисом). Строка подключения задана в `.env`.
